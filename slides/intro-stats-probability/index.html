Statistics vs Probability — Two Directions

Hootsworth: These two words get used interchangeably, but they're actually opposite directions on the same road.
Simple test: if you're told the parameter and asked to describe outcomes → probability. If you're given data and asked to find the parameter → statistics. Task 1 gives you p = 0.58 and asks you to describe the distribution. That's probability.

What IS a Distribution?

Hootsworth: A distribution is a complete portrait of a random variable. It tells you every possible value and exactly how likely each one is. It's the full answer to the question: "what will this variable do?"

After many rolls, the histogram converges to the distribution. The distribution is the theoretical shape the histogram is trying to reach. It tells you:

  • What values are possible
  • How probable each value is
  • Everything else follows: E[X], variance, percentiles...
Key insight: you don't need to run the experiment to know the distribution. If you know the model (fair die → each face has P = 1/6), you know the distribution exactly. That's probability.
KEY CONCEPT — read this carefully

E[X] — The Expected Value

Hootsworth: E[X] is just a weighted average. If you repeated the experiment a million times, what would the average outcome be? That number is E[X]. Let's build it from scratch with dice.

Step 1: the ordinary average

Roll a fair die 6 times and (hypothetically) get each face exactly once. What's the average?

$$\frac{1+2+3+4+5+6}{6} = \frac{21}{6} = 3.5$$

Step 2: rewrite as weighted sum

Each face appeared exactly 1/6 of the time. So the average is:

$$1\cdot\tfrac{1}{6} + 2\cdot\tfrac{1}{6} + 3\cdot\tfrac{1}{6} + 4\cdot\tfrac{1}{6} + 5\cdot\tfrac{1}{6} + 6\cdot\tfrac{1}{6} = 3.5$$

Each value × its probability, summed. That's the definition of E[X].

$$E[X] = \sum_x x \cdot P(X = x)$$
each value × how likely it is, added up
The big "aha": you can never roll a 3.5. E[X] = 3.5 is a property of the distribution, not a prediction of any single throw. It's the number the long-run average converges to after thousands of rolls. "Expected" doesn't mean "I expect to see this next time."
SUB-CHAPTER

E[X] — What It's Not

Three common confusions, each with a concrete counter-example:

1. E[X] is NOT a prediction of one trial

WRONG mental model

"E[X] = 3.5, so I'll probably roll a 3 or 4 next time."

CORRECT mental model

"After 10,000 rolls, the average will be close to 3.5. Any single roll is unpredictable."

2. E[X] does NOT need to be a possible value

Average household size in Germany: 2.06 people. No household has 2.06 people. The number is real and useful for policy, but it's a property of the distribution of all households — not a description of any actual household.

3. E[X] is NOT the most likely value (mode)

Bernoulli(0.58): E[X] = 0.58 ← weighted average (not a possible value) Mode = 1 ← most likely single outcome (since 0.58 > 0.5) These happen to be close but they're different concepts.
Insurance company logic: expected payout per customer = E[X] = €2,000/year. They price premiums above €2,000. No customer costs exactly €2,000 — some cost €0 (no claims), some cost €80,000 (big accident). But across 500,000 customers, the total payout ≈ 500,000 × €2,000. E[X] is the planning number, not the individual prediction.

Variance — How Spread Out Is It?

E[X] tells you the center. Variance tells you how far values typically stray from that center.

Both distributions above have the same E[X]. The difference is variance — how predictable individual values are.

$$\text{Var}[X] = E\!\left[(X - E[X])^2\right] = \sum_x (x-\mu)^2 \cdot P(X=x)$$
average squared distance from the center
$$\text{SD}[X] = \sqrt{\text{Var}[X]} \quad \text{(same units as } X \text{)}$$
For Bernoulli(p): Var[X] = p(1−p). This is maximized at p=0.5 (most uncertain) and goes to 0 as p→0 or p→1 (outcome almost certain). Your task: Var[X] = 0.58 × 0.42 = 0.2436.

PMF vs PDF — Discrete vs Continuous

Two types of random variables need two types of descriptions:

Coin flips, dice, Bernoulli
SUM of all bars = 1

Height, weight, temperature
AREA under curve = probability

Critical distinction: For discrete (PMF), P(X=k) is a real probability. For continuous (PDF), P(X = any specific value) = 0 — probability only exists over intervals. Why? A continuous variable can take uncountably infinite values — you can't split probability 1 across infinitely many individual points without each getting 0. Bernoulli is discrete → PMF → use P(X=0) and P(X=1). Never say "density" for Bernoulli.

The Bernoulli Distribution

Hootsworth: The simplest distribution that can exist: exactly two outcomes, one happens with probability p, the other with probability 1−p. This is your Task 1.

Only two possible values: 0 and 1

$$X \sim \text{Bernoulli}(p)$$
$P(X = 1) = p$   ← "success"
$P(X = 0) = 1-p$ ← "failure"

$E[X] = p$      $\text{Var}[X] = p(1-p)$
Your task: $p = 0.58$, $E[X] = 0.58$, $\text{Var}[X] = 0.58 \times 0.42 = 0.2436$
Why does E[X] = p? Because:
E[X] = 0·(1−p) + 1·p = p
The 0 disappears; only the "for" probability contributes.

Normal Distribution — The Bell Curve

The most common distribution in nature. Appears whenever many small independent factors add up (Central Limit Theorem).

$$X \sim \mathcal{N}(\mu,\, \sigma^2)$$
$\mu = E[X]$   ← center (mean)
$\sigma^2 = \text{Var}[X]$ ← spread (variance)
$\sigma = \text{SD}[X]$   ← same units as $X$
Task 4: historical hammer weights ~ Normal(μ₀=956g, σ₀=17.2g). You're testing whether new production raised the mean. The Normal distribution describes the weights; hypothesis testing decides if the mean shifted.

Exponential & Gamma — Waiting Times

Exponential(λ)

How long until the first event?

  • Time until a lightbulb fails
  • Time until you get a phone call
  • Waiting time at a checkout
$$E[X] = \frac{1}{\lambda} \qquad \text{Var}[X] = \frac{1}{\lambda^2}$$
Memoryless — past doesn’t matter

Task 2: survival function F̄(y) is a mixture of Exponential-type decays in y².

Gamma(α, θ)

How long until the α-th event?

  • Sum of α independent Exponentials
  • Router processing α packets
  • Insurance: total of multiple claims
$$E[X] = \alpha\theta \qquad \text{Var}[X] = \alpha\theta^2$$
Erlang = Gamma with integer $\alpha$

Task 3: router time ~ Gamma(7, θ). Task 6: prior on θ is Gamma(35, 51).

As α increases, the Gamma distribution shifts right and becomes more bell-shaped

Survival Function — What Is It?

Hootsworth: In Task 2, you don't get told the PDF directly. You get the survival function — and you derive the PDF from it. Let's understand what it means first.

Context: $Y$ = hours until an owl call is heard in the forest. It's a continuous random variable ($Y \geq 0$).

$$\bar{F}(y) = P(Y > y)$$
probability the event has not yet happened by time $y$
Relation to CDF: $\bar{F}(y) = 1 - F(y)$
At $y=0$: $\bar{F}(0) = 1$ — certain to still be waiting at start
As $y\to\infty$: $\bar{F}(y) \to 0$ — eventually the event always happens

$\bar{F}(y)$ and $F(y)$ are mirror images: they always sum to 1

Why use the survival function? For waiting-time problems, it's often more natural to specify “how likely is it that nothing has happened yet?” than to specify the density directly. Task 2 gives you $\bar{F}(y)$ — your job is to derive $f(y)$ from it.
SUB-CHAPTER · Task 2 prep

From F̄(y) to PDF — Just Differentiate

The key rule

$$f(y) = -\frac{d\bar{F}}{dy}$$
Why the minus sign? $\bar{F}(y)$ is decreasing, so its derivative is negative. Multiply by $-1$ to get a positive PDF.

Computing probabilities

Instead of integrating the PDF, use the survival function directly:

$$P(a < Y < b) = \int_a^b f(y)\,dy = \bar{F}(a) - \bar{F}(b)$$

This works because $\bar{F}$ is decreasing: a larger value $a$ means less time elapsed, so $\bar{F}(a) > \bar{F}(b)$ and the difference is positive.

Shaded area is identical: $\bar{F}(a)-\bar{F}(b)$ = area under $f(y)$ from $a$ to $b$

Quick sanity check: The PDF $f(y)$ must be $\geq 0$ everywhere and integrate to 1. Since $\bar{F}(0)=1$ and $\bar{F}(\infty)=0$, the total area under $f(y)$ is $\bar{F}(0)-\bar{F}(\infty) = 1-0 = 1$. ✓
SUB-CHAPTER · Task 2 setup

Mixture Survival — Your Task 2

A mixture survival function is a weighted sum of simpler survival curves. Each component represents a different “mode” of behaviour.

$$\bar{F}(y) = w_1\, g_1(y) + w_2\, g_2(y) \qquad \text{(ideally } w_1 + w_2 = 1\text{)}$$

Your specific function

$$\bar{F}(y) = 0.79\, e^{-4y^2} + 0.20\, e^{-6y^2}$$
$w_1 = 0.79$, $a_1 = 4$  |  $w_2 = 0.20$, $a_2 = 6$  |  $0.79 + 0.20 = 0.99 \neq 1$ ← flag this in your notebook

Deriving the PDF

Differentiate each term using the chain rule: $\frac{d}{dy}[e^{-ay^2}] = -2ay\,e^{-ay^2}$

$$f(y) = -\frac{d\bar{F}}{dy} = 0.79\cdot 8y\,e^{-4y^2} + 0.20\cdot 12y\,e^{-6y^2}$$

Computing P(2 < Y < 4):

$$P(2 < Y < 4) = \bar{F}(2) - \bar{F}(4)$$

Sum starts at 0.99 (not 1.0) — document this in the notebook

Exam flag: $\xi_5 + \xi_7 = 0.79 + 0.20 = 0.99 \neq 1$. A true survival function should satisfy $\bar{F}(0) = 1$. Acknowledge this discrepancy explicitly in your notebook write-up.
