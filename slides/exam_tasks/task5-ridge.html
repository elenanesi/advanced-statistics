TASK 5: OLS + RIDGE

Ridge: Degree-10 polynomial, 22 wild points. OLS chases every wiggle. I add a spring that shrinks big coefficients.

Branch ξ₁₅=2. Book: Unit 6.2 (OLS) + 6.4 (ridge).

Design matrix → OLS

Each row of $X$ is $[1,x,x^2,\ldots,x^{10}]$ (22×11). Target $y$.

$\hat\alpha_{\mathrm{OLS}}=\arg\min_\alpha\|y-X\alpha\|_2^2=(X^\top X)^{-1}X^\top y$

Raw powers on $x\in[-17,20]$ make $X^\top X$ absurdly ill-conditioned — tiny noise → huge $\hat\alpha$ swings. That's why ridge exists.

Ridge: OLS + a spring

$\hat\alpha_\lambda=\arg\min_\alpha\big(\|y-X\alpha\|_2^2+\lambda\|\alpha\|_2^2\big)=(X^\top X+\lambda I)^{-1}X^\top y$

$\lambda=0$ → OLS. Huge $\lambda$ → coefficients collapse toward 0 (underfit).

What weight for the penalty?

  • Exam wants reasoning: try a λ path; compare fit vs ‖α‖
  • Practical: CV / holdout SSE; standardize $x$ so λ is comparable
  • Honest line: "I prefer λ=… because ‖α‖ drops sharply while SSE stays same order of magnitude."
